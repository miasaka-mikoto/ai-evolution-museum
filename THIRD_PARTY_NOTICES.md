# Third-party notices

The museum is written as original TypeScript/React code and does not ship third-party images, fonts, model weights, videos, or paper PDFs.

Runtime dependencies:

- React and React DOM — MIT — UI rendering.
- Vite — MIT — development server and production bundling.
- TypeScript — Apache-2.0 — type checking and compilation.
- Vitest — MIT — algorithm and smoke tests.
- lucide-react — ISC — small interface icons (where enabled).

Dependency versions are declared in `package.json`; their license texts remain with the installed packages. No dependency is required at runtime after a production build has been generated.
